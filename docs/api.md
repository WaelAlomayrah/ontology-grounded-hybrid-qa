# API

General endpoints are `/`, `/health`, `/ready`, `/version`, and `/metrics`. Versioned groups provide `/api/v1/chat`, `/retrieve`, `/query-plan`; graph classes/entity/neighbors/search/path/stats; sample/KG2QA/reset/status ingestion; and evaluation run/results. OpenAPI at `/docs` is authoritative. Destructive reset requires `X-Admin-Token`.
